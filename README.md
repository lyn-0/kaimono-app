# 🛍️ お買い物マネージャー

買い物リスト・ほしいものリスト・買ったものリストを1つで管理できるWebアプリです。
インストール不要・サーバー不要で、データはすべてこのPCのブラウザ内（IndexedDB）に保存されます。

## 起動方法

**`起動.bat` をダブルクリック**してください。ローカルサーバーが立ち上がり、ブラウザで `http://localhost:8765` が開きます（黒いウィンドウはアプリを使う間は閉じずにそのままに）。

※ Googleログインを使わない場合は `index.html` を直接ダブルクリックして開いても使えます。

## 機能

### 🛒 買い物リスト
- 日常の買い物メモ。名前と数量を入力して追加
- チェックで購入済みに、「チェック済みを削除」でまとめて整理
- ドラッグ（⠿）で並べ替え

### ⭐ ほしいものリスト
- 商品名・価格・商品ページURL・メモ・ほしい度（★1〜5）を登録
- **スクショ管理**: 編集画面の点線枠をクリックして **Ctrl+V** でスクリーンショットを貼り付け（複数枚OK、クリックで拡大）
- **カテゴリ分け**: カテゴリを設定すると上部のチップで絞り込み
- **並べ替え**: 手動（カードをドラッグ）／価格が安い順／高い順／追加が新しい順
- **⚖️ ジャンル比較**: 同じ「ジャンル」（例: ヘアアイロン）を設定した商品が2件以上あると、価格・ほしい度・スペックの比較表とおすすめ判定を表示
  - スペック（例: 最高温度 / 220）を登録しておくと比較表に反映されます
- **🏆 カテゴリのおすすめ**: カテゴリごとのイチオシを判定（価格の安さ50% + ほしい度35% + スペック充実度15%）

### ✅ 買ったもの
- ほしいものの「🛒 買った！」で移動（購入日を自動記録）
- **📅 使用記録**: 「今日使った」ボタンや日付指定で使用日を記録
- **コスパ自動計算**: 価格 ÷ 使用回数 = 「1回あたり◯円」を表示
- コスパが良い順・使用回数が多い順などで並べ替え
- 「↩」でほしいものリストに戻すことも可能

### 💾 バックアップ
- ヘッダーの「📤 バックアップ」でデータ（画像込み）をJSONファイルに保存
- 「📥 復元」でそのファイルから復元（PCの買い替え時などに）

### 🔑 Googleログイン & ドライブ同期
- ヘッダーの「Googleでログイン」でログインすると、データ（スクショ込み）を自分の
  **Googleドライブのアプリ専用領域**に「☁️ 保存」「☁️ 読込」できます
- 別のブラウザやPCでも、同じGoogleアカウントでログインして「☁️ 読込」すればデータを引き継げます
- **初回のみ設定が必要**: ログインボタン横の「⚙️」を押すと表示される手順に従って、
  Google Cloud Console（無料）で「クライアントID」を発行して貼り付けてください
- Googleの仕様上、ログイン機能は `起動.bat` から開いたとき（`http://localhost:8765`）のみ使えます
- 保存先はアプリ専用領域（appDataFolder）のため、ドライブの通常のファイル一覧には表示されず、
  このアプリ以外からは読み書きできません

## 注意
- データはブラウザごとに保存されます（ChromeとEdgeでは別データになります）
- ブラウザの「閲覧データの削除」でサイトデータを消すとアプリのデータも消えるため、定期的なバックアップをおすすめします
