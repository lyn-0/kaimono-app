# 🛍️ お買い物マネージャー

買い物リスト・ほしいものリスト・買ったものリスト（コスパ計算）を1つで管理できるWebアプリです。
Googleアカウントでログインして使い、データ（スクショ込み）は **Firebase（Cloud Firestore）** に保存されます。
そのため、PC・スマホなどどの端末から開いても自動で同じデータが表示されます。

Firebaseの接続設定（プロジェクト kakeibo-21cf0、家計簿「遊び代管理」と共通）はアプリに組み込み済みのため、
**URLを開いてGoogleでログインするだけで誰でも使えます**。利用者ごとにデータは完全に分離されます。

## 管理者向けメモ（初回のみ）

- Firestore のセキュリティルールが `users/{uid}/{document=**}` を本人のみ読み書き可にしていること
- GitHub Pages などで公開する場合、Firebase Authentication の「承認済みドメイン」に公開先ドメイン
  （例: `あなたのユーザー名.github.io`）を追加すること。`localhost` は最初から許可されています

## 起動方法

- **ローカル**: `起動.bat` をダブルクリック → `http://localhost:8765` が開きます
- **公開版**: GitHub Pages などに `index.html` / `style.css` / `app.js` を置けば、そのURLでどこからでも使えます

## 機能

### 🛒 買い物リスト
- 日常の買い物メモ。チェックで購入済み、「チェック済みを削除」でまとめて整理
- ドラッグ（⠿）で並べ替え

### ⭐ ほしいもの・やりたいこと・スポットリスト
- 登録時に「🛒 ほしいもの」「✨ やりたいこと」「📍 スポット」の種類を選べます

### 📍 スポット（行きたい場所）
- **GoogleマップのURLを貼って保存するだけ**で、スポット名・住所・地域・地図画像が自動登録されます
  （名前の入力は不要。地域は「東京都 港区」のような形でカテゴリに入り、チップで絞り込み・「地域・カテゴリ順」で並べ替えできます）
- 「🚩 行った！」で「買った・やった」リストに移動し、訪問日が記録されます。再訪したら「📅 訪問記録」で追加
- 住所の自動取得には OpenStreetMap（Nominatim）、地図サムネイルには Microlink を利用しています
- やりたいことも、価格（費用）・カテゴリ・ジャンル比較（例: クリニックA vs B）・スクショ・
  「✨ やった！」→実施記録→1回あたりコスパ計算・家計簿同期まで、ものと同じ機能が使えます
- 種類フィルタで「ものだけ」「やりたいことだけ」の表示に切り替え可能
- 商品名・価格・商品ページURL・メモ・ほしい度（★1〜5）・スペックを登録
- **スクショ管理**: 編集画面で **Ctrl+V** 貼り付け、またはファイル選択（スマホは写真ライブラリから）。
  画像は自動で縮小・圧縮してクラウドに保存されます
- **商品情報の自動入力**: 商品ページURLを入れて保存すると、**画像・価格・ジャンル**が
  自動で入力されます（すでに入力済みの項目は上書きしません）
  - 画像: 商品のメイン画像（og:image）、なければページのスクショ
  - 価格・ジャンル: ページの構造化データ（JSON-LD等）やAmazonの価格・パンくず表記から抽出
  - 利用サービス: Microlink（1日約50回）/ mShots / corsproxy.io。取得できないサイトもあります。
    失敗した場合は編集画面でもう一度保存すると再試行されます
- **カテゴリ分け**: チップで絞り込み表示
- **並べ替え**: 手動（ドラッグ）／価格が安い順／高い順／追加が新しい順
- **⚖️ ジャンル比較**: 同じジャンルの商品が2件以上あると、価格・ほしい度・スペックの比較表とおすすめ判定を表示
- **🏆 カテゴリのおすすめ**: カテゴリごとのイチオシを判定（価格の安さ50% + ほしい度35% + スペック充実度15%）

### ✅ 買ったもの
- ほしいものの「🛒 買った！」で移動（購入日を自動記録）
- **📅 使用記録**: 「今日使った」や日付指定で使用日を記録
- **コスパ自動計算**: 価格 ÷ 使用回数 = 「1回あたり◯円」
- コスパ順・使用回数順の並べ替え、「↩」でほしいものに戻すことも可能

### 💰 家計簿「遊び代管理」との連携
- 買ったものカードの「💰」ボタンで、金額・日付・家計簿カテゴリ・メモを確認して家計簿アプリに支出として追加できます
- ダイアログ内のチェックをONにすると、以降は「🛒 買った！」を押した瞬間に**自動で家計簿にも追加**されます（価格未設定の商品は対象外）
- ジャンル名/カテゴリ名が家計簿のカテゴリ名と一致すれば自動で振り分け、一致しなければ「ショッピング」になります
- 同期済みの商品には「💰 家計簿済」バッジが付き、再追加時は二重登録の警告が出ます
- 買い物アプリと家計簿が別のFirebaseプロジェクトの場合、初回のみ家計簿側へのGoogleログインを求められます（同じGoogleアカウントでログインしてください）

### 💾 バックアップ
- 「📤 バックアップ」でデータ（画像込み）をJSONファイルに保存、「📥 復元」で読み込み
- データはFirebaseに保存されるため普段は不要ですが、念のための保険や引っ越し用に

## データの保存場所とプライバシー

- データはあなたのFirebaseプロジェクトの Firestore に、**Googleアカウント（UID）ごとに分離**して保存されます
- セキュリティルールにより、**本人以外は読み書きできません**
- Firestore無料枠（保存1GB・読み取り5万回/日など）は個人利用には十分な容量です
