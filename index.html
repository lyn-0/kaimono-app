    使用記録

      🔑 Googleログインの初期設定

      初回のみ、Google Cloud で「クライアントID」を無料で発行して貼り付ける必要があります（5分程度・クレジットカード不要）。
      ログインすると、アプリのデータ（スクショ込み）を自分のGoogleドライブに保存・復元できるようになります。

      1. Google Cloud Console を開いてGoogleアカウントでログインし、画面上部から新しいプロジェクトを作成（名前は自由。例: kaimono-app）
      2. 左メニュー「APIとサービス」→「ライブラリ」で Google Drive API を検索して有効化
      3. 「APIとサービス」→「OAuth同意画面」で 外部 を選び、アプリ名と自分のメールアドレスを入力して保存。「テストユーザー」に自分のGmailアドレスを追加
      4. 「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuthクライアントID」で、種類は「ウェブアプリケーション」を選択。「承認済みのJavaScript生成元」に http://localhost:8765 を追加して作成
      5. 表示されたクライアントID（xxxx.apps.googleusercontent.com）を下に貼り付けて保存
